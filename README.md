# Stock RL Diagnostic Tool / A股RL持仓诊断系统

基于强化学习的A股持仓诊断工具。7种量价方法 + 舆情分析 + 筹码代理，RL逐日训练专属权重。

## 快速开始

```bash
# 诊断三只持仓
python3 diagnose.py

# 诊断任意股票
python3 diagnose.py 600519

# RL训练（首次使用或积累新数据后）
python3 rl_train.py

# 生成HTML报告
python3 gen_report.py
```

## 架构

```
通用框架（9方法 × 7阶段）──→ 每只票RL专属训练 ──→ 专属权重模型
        │                        │
   舆情数据（东方财富公告）    RL逐日奖惩更新
   筹码代理（缩量/振幅/窄幅）  熵正则防过拟合
```

## 方法集

| 方法 | 说明 |
|------|------|
| 线性趋势 | 20日线性回归外推 |
| 动量延续 | 短期价格动量 |
| 均值回归 | 向均线回归 |
| 跟随大盘 | 大盘涨跌×β |
| α延续 | 超额收益持续性 |
| 行业轮动 | 行业相对强弱 |
| 独立延续 | 独立走势惯性 |
| 舆情驱动 | 公告关键词情绪 |
| 筹码位置 | 缩量/振幅代理 |

## 特征维度

- **价格**: 20日K线 + 大盘指数 + 沪深300
- **舆情**: 东方财富公告API → 关键词情绪打分
- **筹码**: 连续缩量天数 + 振幅收缩 + 窄幅横盘
- **阶段**: 7种市场状态（强牛/弱牛/横盘/弱熊/强熊/独立走强/独立走弱）

## 数据源

- 新浪财经K线（价格）
- 东方财富K线（换手率/振幅/成交额）
- 东方财富公告API（舆情）
- 上证指数 + 沪深300（大盘基准）

## RL训练

- 算法: 批量策略梯度 + 熵正则
- 数据: 2020年5月至今 ~1500个交易日
- 更新: 每20步小批量更新
- 防过拟合: 熵奖励 0.15

## 目录

```

导出文件/           ← HTML诊断报告输出

rl_train.py        ← RL训练脚本
gen_report.py      ← HTML报告生成器
```
