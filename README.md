# 📊 A股RL持仓诊断系统

> 基于强化学习的A股持仓诊断工具。clone 即用，无需API Key。

## 🚀 3分钟上手

```bash
# 1. 克隆
git clone https://github.com/DZZhang1981cn/stock-rl-diagnostic.git
cd stock-rl-diagnostic

# 2. 编辑 portfolio.json，填你自己的持仓
#    {"stocks": {"600519": "贵州茅台", "000858": "五粮液"}}

# 3. 跑诊断（不训练也能直接用）
python3 diagnose.py

# 4. 首次用先训练RL专属模型（约2分钟）
python3 rl_train.py

# 5. 生成HTML报告
python3 gen_report.py
# → 导出文件/持仓诊断_YYYY-MM-DD.html
```

**依赖**: Python 3.7+, curl（macOS/Linux 自带）  
**无需**: pip install / API Key / 数据库

## 🎯 做什么的

每只股票输出一张诊断卡：

```
📍 当前阶段: 独立走强  |  β=0.49  α=+7.0%
📰 近期舆情: 正面（1条公告）
💰 筹码: 振幅收缩 → 筹码稳定
🎯 RL方法权重: α延续34% / 独立延续34% / 跟随大盘16%
🔮 价格参考: ¥11.21 [68%CI: 10.64-11.78]
```

**不是**明天精确到分的预测器——是告诉你当前处于什么状态、该关注什么信号的诊断工具。

## 🔧 配置

编辑 `portfolio.json`：

```json
{
  "stocks": {
    "600519": "贵州茅台",
    "000858": "五粮液",
    "300750": "宁德时代"
  }
}
```

代码规则：`6` 开头用 `sh`（上海），`0/3` 开头用 `sz`（深圳）。

## 🧠 原理

```
9种方法（线性趋势/动量/均值回归/跟随大盘/α延续/行业轮动/独立延续/舆情/筹码）
  ×
7个阶段（强牛/弱牛/横盘/弱熊/强熊/独立走强/独立走弱）
  =
RL逐日训练 → 每只票专属权重 → 组合预测
```

训练数据：2020年5月至今 ~1500个交易日，批量策略梯度 + 熵正则防过拟合。

## 📂 文件

| 文件 | 说明 |
|------|------|
| `diagnose.py` | 日常诊断（读 portfolio.json） |
| `rl_train.py` | RL训练（初次使用或积累数据后跑） |
| `gen_report.py` | 生成HTML报告 |
| `portfolio.json` | 你的持仓配置 |
| `rl_models/` | 训练后的专属权重（自动生成） |
| `导出文件/` | HTML报告输出（自动生成） |

## ❓ FAQ

**Q: 需要装什么？**  
A: Python 3.7+ 即可。数据通过 curl 从公开API拉取，不需要注册。

**Q: 能诊断任意A股吗？**  
A: `python3 diagnose.py 600172` 诊断任意票。`portfolio.json` 里的是默认列表。

**Q: 准确率多少？**  
A: 方向预测约58-65%（不同股票差异大）。坦率说：A股日线接近随机游走，不要期望精准预测——诊断价值大于预测价值。
