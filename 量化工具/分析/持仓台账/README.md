# 持仓台账（单一事实源）

> 建立于 2026-10-03。目的：把散落在 Obsidian 各周期笔记里的**持仓表**汇总成可累计的台账，
> 从而能算真实成本、调仓次数、胜率、回撤、集中度漂移。

## ⚠️ 库只读原则

本目录所有脚本**只读** Obsidian 库（`~/Library/Mobile Documents/iCloud~md~obsidian/Documents/ZZH图书馆/`），
**不新增、不改名、不移动、不删除库内任何文件**。全部产出写在本目录。

## 产出文件

| 文件 | 内容 |
|---|---|
| `positions_timeseries.csv` | 快照序列：每张持仓快照 × 每只票一行（含快照级的总市值/总资产/仓位、可疑标记） |
| `positions_current.csv` | **最新一次**快照的持仓（当前口径：2026-09-27，6 只） |
| `position_events.csv` | 相邻快照对比推导的调仓事件流（建仓/加仓/减仓/清仓/成本变动） |
| `extract_report.txt` | 逐文件提取报告（哪份文件识别到几张表、几票、有无可疑标记） |
| `extract_positions.py` | 提取器（v3）。用法：`python3 extract_positions.py [--check]` |

## 数据源（库内，只读）

```
03_投资研究/股票投资/板块周报/*.md        表头如：代码|名称|成本|股数|现价|市值|盈亏%
03_投资研究/股票投资/周末体检/*.md        表头变体多（含 持股/持股数、9/19收盘、仓位占比…）
03_投资研究/股票投资/每日盘前简报/*.md    实测不含持仓表
03_投资研究/投资日记/*.md                 表头用「股票」而非「名称」
03_投资研究/持仓分析/*.md                 实测不含持仓表
03_投资研究/个股研究/*.md                 实测不含持仓表
```

提取器**按表头名映射列**（库内实测至少 7 种表头变体，按列位置必错）；
持仓表判定要求同时具备 `代码 + 名称 + 股数 + 成本`，以免把观察池/高股息候选表当成持仓。

## 口径

- **数据日期**：笔记里「最新更新YYYY-MM-DD」优先；无则退回文件名日期
- **报告日期**：文件名日期（两者不同时都保留，例：板块周报_2026-08-16 的数据日期是 2026-08-10）
- **成本** = 该笔记里的持仓成本价（不是加权摊薄后成本，跨报告可能口径不一 —— 见下）
- 事件流**自动跳过可疑快照**，避免污染推导

## ⚠️ 已知数据质量问题（需人工确认）

1. **两张快照元数据可疑**（已标记、不参与事件推导）：
   `2026-08-23`（总市值读到 50.6）、`2026-08-30`（3.28）——大概率是笔记里的账户总览表结构不同所致。
2. **库内报告互相矛盾**（2026-09-20 ←→ 2026-09-27 来回跳，疑为其中一份写错）：
   - 小商品城 7100 股 → **100 股** → 7100 股
   - 格力电器 2500 股 → **1000 股** → 2500 股
   - 大唐发电成本 6.135 → **6.154** → 6.135
   - 格力电器成本 39.243 → **41.61** → 39.243
   → 台账如实记录了这一差异；**"哪个数才是对的"需要你确认**（或以后统一以同花顺实盘为准）。
3. **覆盖盲区**：每日盘前简报（17 篇）、持仓分析（2 篇）、个股研究（3 篇）实测都**不含持仓表**，
   所以台账粒度受限于周报/体检/日记这三种。

## 实盘快照（权威口径，2026-10-03 起）

同花顺实盘是持仓的**唯一权威来源**。实测流程为**两步**（脚本本身只读，不涉及下单）：

```bash
# ① 用 CUA 把同花顺主窗口的 AX 全文 dump 到文件（node_repl + computer.observeWindow）
#    ⚠️ 不要沿用 ths_holdings_v2.js 里写死的 pid/windowId，必须动态发现：
#       listApps → 同花顺（cn.com.10jqka.macstockPro）→ listWindows → 取 is_on_screen=true 的主窗口
# ② 解析重建持仓表
python3 parse_ths_ax.py ~/Desktop/AI工作/缓存/ths_state.txt 2026-10-03
```

- 原理：同花顺持仓表格在 AX 树里**没有行结构**，只有带坐标的 `AXStaticText` 单元格；
  脚本用**表头按钮的 x 坐标**建列映射、按 y 分组成行（表头首列实测名为「证券代码」）。
- 输出：`ths_live_<日期>.csv`（代码/名称/市价/盈亏/浮动盈亏比/实际数量/可用余额/成本价/市值/仓位占比/交易市场/股东账户）
- ⚠️ 同花顺当前页面必须在**持仓**页；若停在买入面板会抓不到持仓表（脚本会提示"未识别到持仓表头"）。
- ⚠️ 该窗口上存在「确定买入」按钮 —— **本项目任何脚本都不得点击确认类按钮**（L1 预填规矩）。
