## ⚠️ 实测发现的格式现实（重要）

日报**不是一种格式，而是两族**：

| 族 | 特征 | 可结构化出的东西 |
|---|---|---|
| 板块信号族 | 章节带 `🛒📈 板块信号`，表为 `\| 信号 \| 动态 \|` | 指标原文（数值藏在中文长句里，抽取出 16 行） |
| 归档族 | 章节如 `📊 非农持仓深度分析`，含 `\| 股票 \| 动作 \| 触发价 \| 金额 \| 优先级 \|` | **计划交易 50 条**（价值更高） |

- 56 篇里只有 **1 篇**用 `信号|动态` 表头，**12 篇**含任意表格 → 所以"指标时间序列"很稀疏，这是现实，不是 bug。
- 事件日历的「日期」列是**模糊文本**（`9月19日—23日`、`10月第一周（约周五）`、`10月中旬（约9-10日）`），本提取器**原样保留**，不做不可靠的日期归一化。

## 口径与维护

- 「重要性」列混用两种记法：`⭐⭐⭐⭐⭐`（事件表）与 `★★★☆☆`（计划交易表）——按来源区分，未强行统一
- `EXPOSURE`（事件→板块）与 `HOLDING_SECTOR`（持仓→板块）映射写在 `macro_extract.py` 顶部，**要改就改那里**；矩阵是提示性的，不构成操作建议
- 更新：日报/事件日历有新增后重跑 `python3 macro_extract.py`（56 篇约数秒，文件已本地化）
