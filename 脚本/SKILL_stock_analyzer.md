## 触发

| 用户说 | 模式 |
|------|------|
| "分析 600519" / "看一下 XXX" / "给 XXX 出个报告" | 单票深度分析 |
| "分析持仓" / "看一下持仓" / "持仓表现" | 持仓批量分析 |
| "预估 XXX 后面走势" / "XXX 能到多少" | 价格预测 |

## 流程（6步）

```
第0步 → 政策预扫描（news_policy_scanner.py）
第1步 → 数据拉取（实时报价 + 120日K线）
第2步 → 5+1维打分（盈利/股东/价格/资金代理/筹码代理 + 政策信号）
第3步 → 多模型价格预测（MA趋势+动量+均值回归+加速度+线性回归）
第4步 → 背离诊断（如果基本面偏多但价格在跌，自动触发）
第5步 → 综合报告（操作建议 + 关键位 + 回本计算）
```

---

### 第0步：政策预扫描

```bash
python3 ~/Desktop/AI工作/脚本/news_policy_scanner.py --stocks {股票代码} --days 3
```

输出每只票的政策风向（🟢顺风/⚪中性/🔴逆风），不参与打分但影响置信度。

---

### 第1步：数据拉取

| 数据 | 来源 | 命令 |
|------|------|------|
| 实时报价 | 腾讯 qt.gtimg.cn | `curl -s "http://qt.gtimg.cn/q={sh\|sz}{code}" | iconv -f GBK -t UTF-8` |
| 120日K线 | 新浪 money.finance.sina.com.cn | `curl` → JSON 解析 |

> ⚠️ Python `requests` 在本机不可达，必须用 `subprocess.run(["curl", ...])`。

---

### 第2步：5+1维打分

| 维度 | 数据来源 | 打分 |
|------|------|:--:|
| 盈利性 | 东财 datacenter（ROE/毛利率/净利率/EPS/PE） | -1/0/+1 |
| 股东变化 | 东财 F10 ShareholderResearch（户数环比/Top10持股） | -1/0/+1 |
| 价格走势 | 新浪K线（MA/RSI/布林带/量价配合） | -1/0/+1 |
| 资金流向（代理） | 量价背离代理（价涨量缩=锁仓+1 / 价跌量增=出货-1） | -1/0/+1 |
| 筹码分布（代理） | 量能扩展速度代理（缩量=锁定+1 / 放量=松动-1） | -1/0/+1 |
| **政策信号** 🆕 | news_policy_scanner.py 输出 | **不参与加分，影响置信度** |

综合总分 -5 ~ +5，映射：
- +4/+5 → 强买（高置信）| +2/+3 → 轻仓买 | -1~+1 → 观望 | -2/-3 → 减仓 | -4/-5 → 强卖

---

### 第3步：多模型价格预测

| 模型 | 权重 | 说明 |
|------|:--:|------|
| MA趋势 | 25% | MA5 vs MA10 斜率外推 |
| 5日动量 | 25% | 近5日涨跌幅线性外推 |
| 均值回归 | 20% | 向MA20靠拢，回归强度上限30% |
| 加速度 | 15% | 二阶导（近5日 vs 前5日动量差） |
| 线性回归 | 15% | 近15日OLS，cap ±30% |

输出格式：
```
N天后  方向  ¥预测价  [95%CI低, 95%CI高]
1日后   📈   ¥11.69  [10.97, 12.41]
3日后   📈   ¥11.87  [10.62, 13.12]
5日后   📈   ¥11.90  [10.28, 13.51]
7日后   📈   ¥11.96  [10.05, 13.87]
```

---

### 第4步：背离诊断（条件触发）

当 综合总分≥+1 但 60日跌幅≥-10%，或 5日跌幅≥-3%但同业仅跌<0% 时，自动启用：

| 检查项 | 数据源 |
|------|------|
| 公告扫描 | 新浪公告（排查事件驱动利空） |
| 量能诊断 | 量能扩展（区分主力出货/散户撤离/无人接盘） |
| 同业对比 | 等权代理指数（区分行业β vs 个股α） |
| 量价模式 | 异常放量日识别（找出触发点） |

输出4种背离类型：事件利空/主力出货/行业拖累/真空观望。

---

### 第5步：综合报告

持仓分析输出结构：
```
一、政策风向
二、今日表现 & 盈亏
三、技术面（MA/RSI/量能/关键位）
四、价格预测（1/3/5/7天 + CI）
五、背离诊断（如有）
六、综合判断（操作建议 + 回本计算）
```

单票分析额外包含：大盘对比、同业对比、历史相似情景。
