## 触发

用户说 "选股" / "扫描" / "有什么好票" / "筛一下" / "找找股票" / "全市场扫一遍" → 启用本 skill。

## 流程（3步）

### 第1步：政策预扫描

```bash
python3 ~/Desktop/AI工作/脚本/news_policy_scanner.py --days 3 --json
```

提取政策热点板块，作为后续选股的加权因子。

### 第2步：全市场多因子打分

从东方财富 API 获取全部沪深 A 股（`fs=m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23`），按 5 日涨幅排序取前 200 只。

**评分维度（满分100）**：

| 维度 | 权重 | 计算方式 |
|------|:--:|------|
| 动量 | 30% | 5日涨幅 / 30% 封顶 |
| 持续力 | 15% | 今日涨幅 vs 5日均速 |
| 量能 | 15% | 量比 1.2-2.5 满分 |
| 换手质量 | 10% | 3%-15% 满分 |
| PE合理性 | 15% | 5-20 满分，>80 最低分 |
| 市值适中 | 15% | 50-500亿 满分 |
| **政策加权** 🆕 | **±5分** | 政策顺风板块+5，逆风-5 |

**过滤条件**：
- 排除 PE<0（亏损）、PE>500（估值虚高）
- 排除 今日下跌、量比<0.8、换手>25% 或 <1.5%
- 排除 市值<30亿 或 >2000亿
- 排除 ST / 新股（C字头）

### 第3步：输出

Top 15-20 榜单，含评分明细 + 政策风向 + 板块归属 + 建仓建议。
